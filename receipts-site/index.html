    Use Receipts from your own agentic website

    Receipts publishes two building blocks. Neither needs a key from you or a server of yours.

    1. The public MCP server

    Any agent, in a browser or on a server, can call verify_quote(url, quote) and get_receipt(id). CORS is open and no key is needed.

    {"url": "https://deploytest.theodoikenh.com/oaw-receipts/mcp", "tools": ["verify_quote", "get_receipt"]}

    An open agentic website lists it in an agent's tools as an MCP URL, so its own network can check citations before it answers.

    2. Public receipts

    Every check is stored and can be re-read by anyone at /receipt/<id>. An agent that answers with a citation can attach the receipt id, and the reader can verify it without trusting the agent.

    3. The agent network

    This page's network, receipts_desk, its manifest and runtime are plain static files. Copy them as a starting point for a fact-checking assistant on your own site.

    Public files: agent-manifest.json · receipts_desk.network.json · receipts_desk.hocon · agent-mcp.json · links.json
